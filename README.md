# BotDigest

Telegram-бот для еженедельного дайджеста новостей чата.

## Как это работает

- Участники в любой день пишут боту **в личные сообщения**, что у них произошло — можно
  несколькими сообщениями. Никто в чате не видит эти сообщения.
- В **четверг в 10:00** и **19:00** (по таймзоне из `TIMEZONE`) бот присылает в общий чат
  напоминание скинуть новости в личку.
- В **пятницу в 9:00** бот собирает все накопленные записи, формирует через Claude единый
  дайджест («Имя — абзац») и присылает в общий чат. После отправки все черновики удаляются —
  следующая неделя начинается с чистого листа.

## Настройка

### 1. Токен бота

1. Напишите [@BotFather](https://t.me/BotFather) в Telegram, отправьте `/newbot`, следуйте
   инструкциям.
2. Получите токен вида `123456:ABC-DEF...` — это `BOT_TOKEN`.
3. Приватность (`/setprivacy`) можно оставить в состоянии по умолчанию — боту не нужно читать
   сообщения группы, только писать в неё и получать личные сообщения.

### 2. ID общего чата

1. Добавьте бота в ваш групповой чат.
2. Отправьте в этот чат любое сообщение.
3. Откройте в браузере
   `https://api.telegram.org/bot<BOT_TOKEN>/getUpdates` (подставьте свой токен) и найдите поле
   `"chat":{"id": -100...}` — это и есть `CHAT_ID` (для групп число отрицательное).

### 3. Anthropic API key

Зарегистрируйтесь на [console.anthropic.com](https://console.anthropic.com), создайте API key —
это `ANTHROPIC_API_KEY`.

### 4. Переменные окружения

Скопируйте `.env.example` в `.env` и заполните значениями (локально для теста; на Railway
переменные задаются в настройках проекта, файл `.env` туда не пушится — он в `.gitignore`):

```
BOT_TOKEN=...
CHAT_ID=...
ANTHROPIC_API_KEY=...
TIMEZONE=Europe/Moscow
```

## Локальный запуск

```
pip install -r requirements.txt
export $(cat .env | xargs)   # или экспортируйте переменные вручную
python -m bot.main
```

## Деплой на Railway

1. Залейте репозиторий на GitHub (или используйте этот).
2. На [railway.app](https://railway.app) создайте новый проект → Deploy from GitHub repo.
3. Railway сам обнаружит `Dockerfile` и соберёт образ.
4. В настройках проекта (Variables) добавьте `BOT_TOKEN`, `CHAT_ID`, `ANTHROPIC_API_KEY`,
   `TIMEZONE`.
5. Деплой запустится автоматически, бот начнёт polling.

### Важно про хранение данных

Бот хранит несобранные новости недели в SQLite-файле (`botdigest.db`) на диске контейнера.
На бесплатном плане Railway диск **не переживает передеплой** — если вы обновите код в
середине недели (между четвергом и пятницей), несобранные новости пропадут. Если это критично,
подключите Railway Volume и укажите `DB_PATH=/data/botdigest.db`, примонтировав том на `/data`.

## Настройка расписания/модели

- `TIMEZONE` — таймзона для расписания (по умолчанию `Europe/Moscow`).
- `CLAUDE_MODEL` — модель для сборки дайджеста (по умолчанию `claude-haiku-4-5-20251001`,
  дешёвая и быстрая — расход токенов на дайджест из 13 человек минимальный).

Время самих напоминаний/дайджеста задано в `bot/scheduler.py` (чт 10:00 и 19:00, пт 9:00) —
поменяйте там, если нужно другое время.
